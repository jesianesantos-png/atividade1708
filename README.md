# Sistema de Gerenciamento de Eventos Acadêmicos

## Descrição
Este projeto é um protótipo de interface em HTML para um Sistema de Gerenciamento de Eventos. O foco principal da atividade foi aplicar conhecimentos em git
## Integrantes
* Henrique Gabriel dos Santos Brandão
* Jesiane Silva 

## Funcionalidades
* Tela estruturada para o cadastro de eventos (nome, descrição, data, horário, local, responsável e vagas).
* Tela para consulta e listagem dos eventos disponíveis.
* Navegação funcional interligando as telas de cadastro e listagem.

## Instruções para executar o projeto
1. Clone este repositório em sua máquina utilizando o comando:
   `git clone https://github.com/jesianesantos-png/atividade1708.git`
2. Navegue até a pasta do projeto clonado:
   `cd atividade1708`
3. Como o projeto é construído em HTML estático, não é necessária a instalação de dependências. Basta dar um duplo clique nos arquivos `cadastro.html` ou `listagem.html` para abri-los diretamente em qualquer navegador web.
